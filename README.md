# Research Part B

Continuation of Research Project Part A, examining changes in adherence to COVID-safe behaviours across Australia using weighted descriptive analysis and logistic regression.

## Data source

This project used the Australian component of the Imperial College London–YouGov COVID-19 Behaviour Tracker. The original dataset is available from the [YouGov COVID-19 Tracker repository](https://github.com/YouGov-Data/covid-19-tracker/tree/master/data).

## Repository contents

This repository contains the data-cleaning, exploratory-analysis and modelling notebooks, the final report source, figures, tables and saved numerical outputs used in the report.
